# Формат файлов уроков

Каждый урок хранится в виде Markdown-файла (`.md`) с YAML front matter в папке `lessons/<course_slug>/`.

## YAML Front Matter

В начале каждого файла — блок YAML между `---`:

```yaml
---
title: "Название урока"
order: 1
tags: ["тег1", "тег2"]
prerequisites: "Что нужно знать перед уроком"
objective: "Чему вы научитесь"
---
```

### Поля

| Поле | Обязательное | Тип | Описание |
|------|-------------|-----|----------|
| `title` | Да | `string` | Название урока. Используется для заголовка и генерации URL-slug. |
| `order` | Нет | `int` | Порядковый номер урока. Если не указан, берётся из числового префикса имени файла (например, `03-...` → 3). |
| `tags` | Нет | `list[string]` | Список тегов для категоризации. |
| `prerequisites` | Рекомендуется | `string` | Описание того, что нужно знать перед уроком. |
| `objective` | Рекомендуется | `string` | Конкретная цель урока: что слушатель сможет делать после его завершения. |

## Контент (Markdown)

После front matter идёт тело урока в формате Markdown. Поддерживаются:

- Заголовки `##`, `###`, `####`
- Списки, таблицы, цитаты (`>`)
- Fenced code blocks с указанием языка: ` ```python `
- Подсветка синтаксиса через Pygments (автоматически)

## Slug-генерация

URL-идентификатор урока (slug) генерируется из поля `title`:
- Приведение к нижнему регистру
- Замена пробелов и не-буквенных символов на дефисы
- Удаление повторяющихся дефисов

Например, `"Идиоматический Python: Comprehensions"` → `идиоматический-python-comprehensions`.

## Добавление нового курса

1. Создайте папку в `lessons/` с slug-именем курса (например, `my-course`).
2. Добавьте `.md` файлы с YAML front matter.
3. Добавьте запись в список `COURSES` в `app.py`:

```python
{
    "slug": "my-course",
    "title": "Мой курс",
    "description": "Описание курса.",
    "icon": "📚",
    "level": "Средний",
    "duration": "~5 часов",
}
```

4. Перезапустите сервер — уроки автоматически подхватятся.

## Примечания

- **Порядок уроков**: если не указано поле `order`, используется числовой префикс имени файла. Рекомендуется именовать файлы как `01-название.md`, `02-название.md` и т.д.
- **Кодировка**: UTF-8.
- **Подсветка кода**: указывайте язык после открывающих ``` для корректной подсветки.
- **Копирование кода**: кнопка «Копировать» добавляется автоматически к каждому блоку кода.

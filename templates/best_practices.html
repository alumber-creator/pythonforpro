🐍 Best Practices: Python для профессионалов

Свод правил, идиом и рекомендаций, которые отличают код профессионала от кода новичка.

1. PEP 8 — стиль как закон

PEP 8 — это официальное руководство по стилю кода Python. Его соблюдение — не вопрос вкуса, а профессиональный стандарт.

  • Отступы: 4 пробела (никаких табуляций).
  • Длина строки: 79 символов для кода, 72 для docstrings.
  • Имена: snake_case для функций и переменных, PascalCase для классов, UPPER_CASE для констант.
  • Пробелы: вокруг операторов, после запятых, но не внутри скобок.
  • Импорты: стандартная библиотека → сторонние → локальные, каждый на новой строке.

Автоматизируйте с black и ruff — не тратьте время на ручное форматирование.

2. Zen of Python

Запустите import this в интерпретаторе. Ключевые принципы:

  • Beautiful is better than ugly. Код должен быть эстетичен.
  • Explicit is better than implicit. Явное лучше неявного.
  • Simple is better than complex. Простое лучше сложного.
  • Readability counts. Читаемость имеет значение.
  • There should be one — and preferably only one — obvious way to do it.

3. Идиомы Python

3.1. Используйте comprehensions

# ❌ Анти-паттерн
result = []
for item in items:
    if condition(item):
        result.append(transform(item))

# ✅ Идиоматично
result = [transform(item) for item in items if condition(item)]

3.2. Используйте in для проверки вхождения

# ❌ Анти-паттерн
if x == "a" or x == "b" or x == "c":
    ...

# ✅ Идиоматично
if x in {"a", "b", "c"}:
    ...

3.3. Распаковка вместо индексов

# ❌ Анти-паттерн
first = items[0]
second = items[1]
rest = items[2:]

# ✅ Идиоматично
first, second, *rest = items

3.4. enumerate вместо range(len(...))

# ❌ Анти-паттерн
for i in range(len(items)):
    print(i, items[i])

# ✅ Идиоматично
for i, item in enumerate(items):
    print(i, item)

3.5. zip для параллельной итерации

# ❌ Анти-паттерн
for i in range(min(len(a), len(b))):
    print(a[i], b[i])

# ✅ Идиоматично
for x, y in zip(a, b):
    print(x, y)

3.6. Контекстные менеджеры

# ❌ Анти-паттерн
f = open("file.txt")
try:
    data = f.read()
finally:
    f.close()

# ✅ Идиоматично
with open("file.txt") as f:
    data = f.read()

4. Типизация

Используйте type hints везде в новом коде. Это не просто документация — это инструмент для статического анализа.

from typing import Optional, Union

def get_user(user_id: int) -> Optional[dict[str, str]]:
    """Возвращает пользователя или None."""
    ...

# Python 3.10+:
def process(data: str | int) -> list[str]:
    ...

❓ Часто задаваемые вопросы

Для кого эти курсы?

Для опытных программистов, которые уже владеют хотя бы одним языком (Java, C++, JavaScript, C#, Go, Rust и т.п.) и хотят быстро и глубоко освоить Python. Мы не объясняем, что такое цикл или переменная — мы показываем, чем Python отличается и как использовать его уникальные возможности.

Чем этот сайт отличается от других курсов по Python?

Большинство курсов ориентированы на новичков в программировании. Здесь же:

  • Фокус на идиоматическом Python, а не на основах программирования.
  • Сравнение с Java, C++, JavaScript в каждом уроке.
  • Акцент на «почему», а не только на «как».
  • Продвинутые темы: дескрипторы, метаклассы, async/await, C-расширения.
  • Весь код соответствует PEP 8 и Zen of Python.
Нужно ли знать Python, чтобы начать?

Нет. Курс «Python для профессионалов: Быстрый старт» проведёт вас от установки до уверенного владения базовым синтаксисом за 5 уроков. Если вы уже знаете Python, начните с «Идиоматического Python».

Какой порядок прохождения курсов?

Рекомендуемый порядок:

  1. Python для профессионалов: Быстрый старт — если вы новичок в Python.
  2. Идиоматический Python — пишите код как настоящий Python-разработчик.
  3. Инструменты и экосистема — настройте рабочее окружение.
  4. Качество кода и тестирование — профессиональный подход.
  5. Продвинутые возможности — декораторы, метаклассы, дескрипторы.
  6. Асинхронный Python — конкурентность без потоков.
  7. Производительность и оптимизация — выжмите максимум.
Бесплатно ли это?

Да, все материалы полностью бесплатны и открыты. Вы можете запустить этот сайт локально (см. README) или использовать публичную версию.

Как добавить свой урок или курс?

Ознакомьтесь со страницей формата уроков. Создайте Markdown-файл с YAML front matter, поместите его в нужную папку в lessons/ — сервер автоматически подхватит его при перезапуске.

Какие версии Python рассматриваются?

Основной фокус на Python 3.11+, с упоминанием новых возможностей Python 3.12 и 3.13. Python 2 не рассматривается вообще.

Есть ли поддержка других языков интерфейса?

Пока интерфейс только на русском. Контент уроков на русском с английскими терминами и примерами кода.

📄 Формат файлов уроков

Каждый урок — это Markdown-файл с YAML front matter. Сервер автоматически сканирует папки и строит навигацию.

Структура каталога

lessons/
├── python-fast-track/          # slug курса
│   ├── 01-why-python.md        # 01-префикс задаёт порядок
│   ├── 02-syntax-basics.md
│   └── ...
├── idiomatic-python/
│   ├── 01-zen-of-python.md
│   └── ...
└── ...

YAML Front Matter

Каждый файл начинается с блока YAML между ---:

---
title: "Идиоматический Python: Comprehensions"
order: 2
tags: ["comprehensions", "list", "dict", "set"]
prerequisites: "Базовый синтаксис Python, циклы, функции"
objective: "Научиться заменять циклы на comprehensions для читаемого и быстрого кода"
---

Поля front matter

ПолеОбязательноеОписание
titleДаНазвание урока. Также используется для генерации slug.
orderНетПорядок урока в курсе (целое число). Если не указан, используется числовой префикс имени файла.
tagsНетСписок тегов для фильтрации и поиска.
prerequisitesРекомендуетсяЧто нужно знать перед уроком.
objectiveРекомендуетсяЦель урока — что слушатель сможет делать после.

Подсветка кода

Используйте fenced code blocks с указанием языка. Поддерживаются все языки, известные Pygments:

```python
def hello():
    print("Hello, World!")
```

```java
public static void main(String[] args) {
    System.out.println("Hello");
}
```

```javascript
const hello = () => console.log("Hello");
```

Добавление нового курса

  1. Создайте папку в lessons/ с slug-именем курса (например, my-course).
  2. Добавьте Markdown-файлы уроков с YAML front matter.
  3. Добавьте запись о курсе в список COURSES в app.py.
  4. Перезапустите сервер.
